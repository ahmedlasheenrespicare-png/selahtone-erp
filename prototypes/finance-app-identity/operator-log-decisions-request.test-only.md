# بيانات المشغّل المطلوبة لإغلاق فجوة السجل الزمني

**طلب معلومات وصفية فقط؛ ليس طلب تنفيذ أو تفعيل أو نشر أو استعادة.** لا تكتب `DATABASE_URL` أو `DIRECT_URL` أو كلمة مرور أو token أو قيمة سرية أو صفوف بيانات أعمال. لا تخمّن الجلسة أي حقل. الحالة قبل الرد: `AWAITING_OPERATOR_DESCRIPTIVE_INFORMATION` والمانع مفتوح.

لكل حدث، مطلوب:

1. **التاريخ والوقت كاملان مع السنة والمنطقة الزمنية**، ويفضل ISO 8601 مثل `2026-11-11T14:35:00+02:00`. إن كان المصدر يعرض توقيتًا محليًا فاذكر المنطقة بوضوح.
2. **من اتخذ أو نفذ القرار**: اسم وصفي أو دور مشغّل، دون بيانات دخول.
3. **القرار والإجراء الفعليان**، والتمييز بين ما قُصد وما حدث فعلًا.
4. **مصدر المعلومة**: سجل Render أو قرار مباشر من المشغّل أو مرجع نشر/commit عام. لا تلصق أسرارًا أو بيانات أعمال.

## قاعدة الإغلاق

يُغلق `LOG_YEAR_TIMESTAMPS_AND_OPERATOR_DECISIONS_SUPPLIED` فقط عندما تكون الأحداث الثلاثة موثقة بالسنة والطوابع ومَن/متى/القرار، مع تمييز رواية المشغّل عن الدليل المستقل. وجود هذه البيانات لا يثبت ضبط `DATABASE_URL`، ولا يفتح بوابة التفعيل، ولا يحول الرواية إلى إثبات انتقال نقد أو نجاح استعادة بيانات. إذا لم يعد مصدر مستقل موجودًا، يُسجل ذلك صراحةً بدل اختلاق طوابع أو نسبة قرار لشخص غير معروف.
