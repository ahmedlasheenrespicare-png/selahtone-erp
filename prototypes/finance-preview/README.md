# معاينة المصروفات والعهد النقدية

هذه **معاينة تصورية منفصلة وليست ميزة فعلية**. لا تستخدم Prisma أو ملفات التطبيق أو قاعدة بيانات أو تخزين المتصفح، ولا تتصل بالشبكة أو تنفّذ دفعًا. جميع الفروع والمبالغ والأسماء والحركات افتراضية، وتعود الحالة الأولية عند تحديث الصفحة. استخدم بيانات وهمية فقط.

تبديل دور المدير والمحاسب وموظف الفرع محاكاة للشرح، وليس مصادقة أو صلاحيات آمنة. لا تُنقل هذه الشيفرة إلى الإنتاج كبديل للمعاملات والصلاحيات على الخادم.

تُظهر المعاينة مراحل طلب المصروف واعتماده وتسجيل دفعه، وتاريخ الدفع الفعلي، والتسليم بين خزنة وعهدة، والتحذير قبل رصيد سالب، وأثر التحصيل النقدي مقابل الوسائل الأخرى. يمكن إدخال مستفيد ورقم مستند وقيمة ضريبة توضيحية اختياريًا؛ لا تُحتسب الضريبة تلقائيًا ولا تُعد الخانة الفارغة صفرًا. تاريخ الجرد والأرصدة ثابتان ووهميان؛ يُظهر المثال تسجيل صرف نقدي سابق للجرد تاريخيًا دون خصم آخر بعد التأكيد، ومع يوم الجرد يسأل عن ترتيب الحدثين. إدخال أرصدة البداية وتعديلها ومعالجة التحصيلات والمردودات التاريخية غير منفذة. بعد تسجيل مصروف تجريبي مدفوع، يتيح زر «طلب مراجعة» إدخال سبب ومبلغ مقترح اختياري؛ يظهر طلب مفتوح دون تغيير المصروف أو الرصيد أو إنشاء حركة، ولا توجد تسوية أو إغلاق للطلب في المعاينة. مثال التحصيل منفصل ولا ينشئ فاتورة أو يتحقق من مستحق العميل. لا تدعم المعاينة ردود المبيعات أو رفع المستندات أو إدارة البنود أو التسوية الفعلية للتصحيحات أو حسابات بنكية.

## التشغيل والاختبار

من جذر المستودع:

```bash
python3 -m http.server 4175 --bind 0.0.0.0 --directory prototypes/finance-preview
node --test prototypes/finance-preview/model.test.mjs
```

يستفيد مجلد `fonts` من ملفات الخط المحلية الموجودة في معاينة البيع، بترخيص SIL Open Font License المذكور في `prototypes/sales-preview/fonts/LICENSE.txt`. يُمنع الاتصال الخارجي عبر سياسة المحتوى في الصفحة.

قبل أي تطبيق فعلي: تُراجع قرارات الأرصدة الافتتاحية والتصحيح والجرد ومستندات المصروفات والضرائب والحركات السابقة، ويُراجع مخطط الإنتاج ونسخته وصلاحيات حساب التطبيق. يلزم اختبار تنفيذ خادمي بقاعدة معزولة وموافقة منفصلة على أي ترقية أو نشر.
