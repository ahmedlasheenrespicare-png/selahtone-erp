# معاينة البيع والمرتجعات — نموذج منفصل

هذه **معاينة تفاعلية وليست ميزة إنتاجية**. لا تستورد ملفات التطبيق أو Prisma، ولا تتصل بقاعدة بيانات أو بوابة دفع، ولا تحفظ أي شيء في المتصفح أو على الخادم. كل ما يظهر من أصناف وفروع وأسعار ومعدلات ضريبة وسيريالات وعملاء خيالي، وتعود الحالة إلى أمثلتها عند تحديث الصفحة. استخدم بيانات وهمية فقط.

تبديل الأدوار محاكاة في المتصفح لشرح التجربة، **وليس مصادقة أو صلاحيات آمنة**. لا يجوز نقل هذه الشيفرة كما هي إلى الإنتاج. حساب الضريبة هنا توضيحي فقط، وليس قرارًا ضريبيًا أو فاتورة إلكترونية رسمية. مبالغ العميل المستحقة بعد المرتجع تُعرض كالتزام؛ لا تسجل المعاينة رد الأموال الفعلي أو تعالج الدفع.

## التشغيل والاختبار

من جذر المستودع:

```bash
python3 -m http.server 4173 --bind 0.0.0.0 --directory prototypes/sales-preview
node --test prototypes/sales-preview/model.test.mjs
```

المعاينة ثابتة وتستخدم ملفات محلية فقط، وتقيّد طلبات الاتصال الخارجي عبر سياسة المحتوى. خطوط IBM Plex Sans Arabic من حزمة المشروع ومرخصة وفق `fonts/LICENSE.txt`.

قبل تطوير إصدار فعلي، يلزم تحديد كيفية تسجيل دفع المبالغ المستحقة للعميل وصلاحيات ذلك، ومراجعة معدلات الضريبة والأسعار الشاملة مع المحاسب، ومراجعة مخطط قاعدة البيانات الموجودة والنسخة الاحتياطية، وتنفيذ المعاملات والتزامن وسجل الحركات والصلاحيات من الخادم واختبارها على قاعدة منفصلة. لا تُجرى أي ترقية أو نشر للإنتاج تلقائيًا.
