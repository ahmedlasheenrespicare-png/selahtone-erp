5. **اختبارات انحدار:** أُثبت أن سحب الصلاحية بعد قرار HTTP يمنع الحفظ ولا يترك فاتورة أو تحصيلًا أو طلبًا جزئيًا، وأن استثناء الحساب يعمل. اختُبر مسار الهوية محليًا على PGlite فكانت النتيجة `FAIL` المتوقعة لعدم استخدام `selahtone_app`، مع `rollbackObserved=true` ومنع غير الأدمن.
